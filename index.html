The formula chain, step by step (generic -- applies to every folder)

1
Quantity in, typed by the estimator
A count of cases/coils/equipment items, sourced from a drawing schedule or a scope letter, or an aggregate judgment call when neither cleanly states a total.
2
XLOOKUP converts quantity into material $ and labor hours
Every category (Display Cases, Evaporators, Equipment) has its own small rate table; the formula is always qty x XLOOKUP(type, rate table).
3
Hours classified as ST / OT / DT
Sometimes automatic, sometimes a manual estimator choice (e.g. a "night work" clause pushing everything into Overtime).
4
Hours blended across 5 roles, by a per-project %
Foreman / Startup / Journeyman / Apprentice / Tradesman -- a staffing-policy input.
5
Each role's rate = base wage x burden, with additive OT/DT loading
ST cost-rate = base x (burden+0) OT cost-rate = base x (burden+0.5) DT cost-rate = base x (burden+1) Minneapolis region code "539" is a hardcoded exception: +1/+2 instead of +0.5/+1
6
Cost becomes Sell via reverse-margin
Sell = Cost ÷ (1 - margin%) NOT Cost x (1+margin%)

Naming trap confirmed on HEB 57: BidCalc's own "Markup" column shows a different number than SUMMARY's "Margin %" column for the exact same dollars -- e.g. Margin 25% shows up in BidCalc as Markup 33.3%. Same economics: markup-on-cost = margin/(1-margin). Not a discrepancy, just two tabs describing the same relationship differently -- don't treat a mismatched-looking percentage as an error without checking which convention that tab uses.

7
Tax: category is automatic, rate is always manual
Tax category comes from an XLOOKUP on State + Construction-Type into the TAX TABLE tab. The tax rate is always typed by hand after the estimator manually Googles it -- a HYPERLINK formula literally opens the search, with a note warning to verify multiple results. This is the one universally manual step in an otherwise formula-driven chain, on every folder checked so far.
8
Everything rolls into BidCalc
Labor + Materials + Rentals + Subcontractors + Contingency + Warranty + Tax, each with its own category-specific margin, summed into one Total Bid.
